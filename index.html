Baton

iPhone · iOS 26 or later

Hand off your household with confidence.

Baton keeps everything a sitter needs to know about your kids, pets and home — and turns it into one calm, tailored brief you can AirDrop, message or print.

It asks, you answer

Baton interviews you with the questions a babysitter, pet sitter or house sitter would ask. Answering is the data entry.

Only what's needed leaves

Door codes don't go to the babysitter. Medical details don't go to the house sitter. You can change that per brief.

One emergency card

Address, contacts, allergies, poison control — on one screen, in Spotlight, Siri and a widget.

Private by architecture

No account. No cloud. No analytics. Baton never connects to the internet. Optional Face ID lock and a one-file backup you own.

Support

Questions, bugs or ideas: open an issue on GitHub. Please don't include your family's information in a public issue — a description of the problem is enough.

Backups. Settings → Data → Export backup writes a .batonbackup file to Files (or iCloud Drive, if you keep Files there). Import it on a new iPhone from the same screen. Your iPhone's own iCloud or computer backup also includes Baton's data.

App lock. If Face ID fails, Baton falls back to your device passcode. If you disable Face ID for Baton in iOS Settings, the lock uses the passcode only.

Privacy

Baton does not collect any data. Read the privacy policy.
